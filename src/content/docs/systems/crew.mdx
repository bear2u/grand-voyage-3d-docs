항해사는 능력과 직책이 있는 일행이고, 선원 수는 배의 운항과 백병전을 좌우합니다. 배가 느릴 때는 명부에서 항해장을 바꾸기 전에 기함의 최소 선원부터 확인하세요.

## 어느 문으로 들어갈까

| 장소 | 할 수 있는 일 |
| --- | --- |
| 술집 | 선원 고용, 대접, 소문 수집, 항해사와의 만남. 주사위와 운수 바퀴가 열려 있으면 당일 횟수와 참가비를 보고 즐깁니다. |
| 여관 | 날을 보내며 몸을 회복합니다. 기한 있는 의뢰를 맡았다면 며칠을 보낼지 먼저 정하세요. |
| 교회·모스크·사원 | 기도는 하루 한 번입니다. 기부로 사기를 올리고 금액에 따라 지역 평판도 얻습니다. |
| 도구점 | 무기·방어구·항해 도구와 여행 물품을 삽니다. 착용 중인 장비는 벗긴 뒤 팔 수 있습니다. |
| 조합 | 의뢰판, 발견물 보고, 해도·시세·해적 정보, 은행 창구를 이용합니다. |

## 직책은 어떤 능력을 쓰나

| 직책 | 효과 |
| --- | --- |
| 항해장 | 항해술 → 함대 속도 (50 넘는 한 점에 0.2%, 8% 까지) |
| 포술장 | 지식 → 해전 포격 (우리 배 통솔 +, 50 넘는 넉 점에 한 점, 10 까지) |
| 갑판장 | 용기 → 백병 (우리 배 검술 +, 10 까지) |
| 측량사 | 지식 → 발견·관측·흔적 찾기 거리 (25% 까지) |
| 주계장 | 매력 → 사는 값 −·파는 값 + (4% 까지) |
| 선의 | 지식 → 날마다 선원 건강 + (3 까지), 괴혈병 손실 − |

술집의 **일행 명부와 직책**에서 담당자를 고르고, 개인 명부에서 장비를 확인하세요. 칼은 공격과 속도, 방어구는 방어를 살펴 결투에 나설 사람에게 먼저 줍니다. [도구와 장비 도감](/atlas/items/)
