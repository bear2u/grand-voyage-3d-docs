## 새 항해와 이어하기

13부 본편은 **새로 시작**, 마리나·니콜라·야코의 개별 항차는 **선장전**에서 시작합니다. 선장전 기록은 선장별로 나뉩니다. 기록이 있는 카드에는 **이어하기**와 **새 항차**가 표시됩니다. 같은 인물의 본편과 선장전도 각각 이어갈 수 있습니다. [선장전 시작하기](/start/captains/) 같은 이야기의 저장 기록이 있으면 덮어쓰기 전에 확인 창이 열립니다. 이전 항해를 계속하려면 **이어하기**에서 이야기와 날짜를 확인하세요.

## 세이브를 남길 때

자동 저장 한 칸과 직접 저장 세 칸을 씁니다. 선택 전 상태를 보관하려면 마을이나 항해 중에 **메뉴 → 저장 칸**을 열어 빈 칸에 직접 저장하세요. 이어하기에서는 장소와 날짜를 확인한 뒤 고릅니다. 전투 도중의 한 합을 직접 저장해 되감는 방식은 지원하지 않습니다.

**내보내기**는 선택한 저장 칸의 사본을 만듭니다. **가져오기**는 최근 내보낸 사본을 표시된 칸에 되살립니다. 빈 칸이 없으면 저장 3이 대상이므로 이름을 확인하세요. 웹의 내보낸 사본도 그 브라우저의 게임 저장 공간에 남습니다. 브라우저 데이터를 지우거나 다른 기기로 옮길 때의 백업으로 간주하지 마세요.

음악·효과음과 조작 도움은 설정에서 조절합니다. 이야기를 이어가기 전에 전투만 익히고 싶을 때는 시작 화면의 **전투 연습**을 사용하세요.

## 항해 설정 고르기

**보급**은 보통·쉬움·끔 중에서 고릅니다. **보급 경유**를 켜면 자동 항해 때 목적지까지 물과 식량이 모자랄 경우 들를 항구를 찾습니다. **출항 점검**은 준비가 넉넉할 때만 건너뛸 수 있습니다. **판도 턴**은 세력의 정산 간격을 바꾸는 설정입니다. 배 자체의 이동 배속은 바다에서 **선장 메뉴 → 항해**에서 바꾸세요.

## 음악은 들리는데 항구와 바다가 조용할 때

시작 화면이나 게임 중 메뉴의 **설정**에서 **음악**과 **효과음**을 따로 조절하세요. 음악은 배경 음악과 짧은 축하 음악의 크기를 함께 바꿉니다. 효과음은 버튼·전투 소리뿐 아니라 바람과 파도 같은 주변 소리에도 적용됩니다. 둘 다 들리지 않으면 게임 중 메뉴를 여세요. **소리 켜기**가 표시되면 눌러 음소거를 해제합니다.
