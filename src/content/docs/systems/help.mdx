| 보이는 현상 | 가장 먼저 확인할 곳 |
| --- | --- |
| 부두에서 출항을 고를 수 없다 | [출항 점검](/start/first-voyage/)에서 최소 선원, 물, 식량을 봅니다. 짐칸이 가득 차면 상품을 일부 내려야 보급이 들어갑니다. |
| 지정한 항구에 왔는데 대사가 없다 | 수첩의 다음 목표에 적힌 **건물**, 가진 물건의 **수량**, 방문 **순서**를 봅니다. |
| 새 배의 금액을 모았는데 주문이 안 된다 | [조선소](/systems/fleet/)에서 선종의 판매 항구, 공업 수준과 열린 등급을 따로 봅니다. |
| 포를 쏠 수 없거나 예상보다 약하다 | 거리·남은 포탄·시야와 뱃머리 방향을 봅니다. 산탄은 사거리가 짧고 옆구리 쪽이 포를 더 많이 씁니다. |
| 결정타 단추가 없다 | [일기토](/systems/duel/)에서 상대 기세와 자세를 함께 봅니다. 내 자세까지 무너졌다면 먼저 버텨야 합니다. |
| 항구 주인이 그대로다 | 전쟁 해도에서 다툼 여부와 판도 턴을 봅니다. 계약한 깃발, 세력 평판, 항구 주인은 서로 다른 정보입니다. |
| 괴물 소문을 들었는데 만나지 못한다 | [괴물 추적](/systems/explore/)에서 해역, 철, 수준, 조사한 흔적을 봅니다. |
| AI가 멈췄다 | 오른쪽 위 운행 표시에서 일시정지 여부와 현재 할 일을 확인합니다. 직접 입력을 멈춘 뒤 다시 이어가세요. |
| 다른 브라우저에서 이어하기가 비어 있다 | 원래 쓰던 브라우저와 게임 주소에서 저장 칸을 확인하세요. |
| 도전과제에 항목이 보이지 않는다 | 현재 지정된 도전과제 목록은 비어 있습니다. 장부와 수첩에서 항해 기록을 확인할 수 있습니다. |
