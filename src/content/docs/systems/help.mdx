| 보이는 현상 | 가장 먼저 확인할 곳 |
| --- | --- |
| 방금 들은 목적지를 잊었다 | [수첩 → 지금 할 일](/systems/notebook/)에서 목적지와 시설을 확인하세요. 대화 중에는 화면의 퀘스트 버튼을 누르세요. |
| 선박 상세에 물자 추가 버튼이 없다 | 바다에서는 보유량을 볼 수 있습니다. [항구 관리소의 배별 적재](/systems/provisions/)에서 배를 골라 물자를 더 실으세요. |
| 부두에서 출항을 고를 수 없다 | [출항 점검](/start/first-voyage/)에서 최소 선원, 물, 식량을 봅니다. 짐칸이 가득 차면 상품을 일부 내려야 보급이 들어갑니다. |
| 지정한 항구에 왔는데 대사가 없다 | 수첩의 다음 목표에 적힌 **건물**, 가진 물건의 **수량**, 방문 **순서**를 봅니다. |
| 새 배의 금액을 모았는데 주문이 안 된다 | [조선소](/systems/fleet/)에서 선종의 판매 항구, 공업 수준과 열린 등급을 따로 봅니다. |
| 포를 쏠 수 없거나 예상보다 약하다 | 거리·남은 포탄·시야와 뱃머리 방향을 봅니다. 산탄은 사거리가 짧고 옆구리 쪽이 포를 더 많이 씁니다. |
| 결정타 단추가 없다 | [일기토](/systems/duel/)에서 상대 기세와 자세를 함께 봅니다. 내 자세까지 무너졌다면 먼저 버텨야 합니다. |
| 선장전 첫 항차를 마쳤는데 다음 장이 안 열린다 | 소속 세력의 관저에서 임무를 받으세요. 무소속 마리나는 원하는 세력과 계약하거나 자유 항해를 계속할 수 있습니다. [선장별 진행](/start/captains/) |
| 공훈 3,000인데 부함대를 보낼 수 없다 | 우리 항구의 관저 집무실에서 빈 부함대 자리, 기함 외에 맡길 수 있는 배, 파견되지 않은 항해사를 확인하세요. |
| 항구 쟁탈전에서 이겼는데 깃발이 그대로다 | 공격 승리는 다음 판도 정산에 소유권으로 반영됩니다. 방어 승리면 기존 깃발을 지킵니다. [쟁탈전 결과 확인](/start/captains/) |
| 괴물 소문을 들었는데 만나지 못한다 | [괴물 추적](/systems/explore/)에서 해역과 출현하는 달을 확인하세요. 흔적 셋은 서로 다른 날에 모읍니다. 권장 레벨은 난도 표시입니다. |
| 다른 브라우저에서 이어하기가 비어 있다 | 원래 쓰던 브라우저와 게임 주소에서 저장 칸을 확인하세요. |
| 도전과제에 항목이 보이지 않는다 | 현재 지정된 도전과제 목록은 비어 있습니다. 장부와 수첩에서 항해 기록을 확인할 수 있습니다. |
